# Xclusive Dent - Clínica Dental Huánuco

Sitio web estático moderno de alta conversión desarrollado para **Xclusive Dent**, clínica odontológica líder en Huánuco, Perú.

## Características Principales
- **100% Frontend (HTML5, Vanilla CSS3 y JavaScript ES6+)**: Carga instantánea, sin backend y con costo de servidor $0.
- **Embudo de Agendamiento Directo a WhatsApp**: Selector interactivo de sede (Bolívar o Amarilis), tratamiento y fecha que autocompila el mensaje en WhatsApp.
- **Comparador Interactivo de Sonrisas**: Slider de antes y después para casos de ortodoncia de precisión.
- **Test de Sonrisa ("Smile Quiz")**: Diagnóstico express interactivo en 3 pasos con beneficio promocional.
- **Indicador de Horarios en Tiempo Real**: Notifica automáticamente si la clínica está abierta o cerrada según la hora local de Huánuco.
- **Identidad de Marca**: Diseño basado en los colores del logo (Azul Marino Profundo, Cian Eléctrico y Blanco Puro).
- **SEO Local**: Marcado de datos estructurados Schema.org `Dentist` para ambas sedes.

## Ejecución Local
```bash
node server.js
```
Abre en tu navegador: [http://localhost:3000](http://localhost:3000)
